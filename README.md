# Nordis

Software and design studio website: static frontend plus a small Express API.

All design, copy and data are original placeholders.

## Run

```
cd backend
npm install
npm start      # http://localhost:3000
npm test
```

- `frontend/` static pages (Home, Services, Work, About, Insights, Careers, Contact)
- `backend/` Express API (`/api/*`) that also serves the frontend
